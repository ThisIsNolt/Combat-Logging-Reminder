Combat Log Reminder

A simple addon for World of Warcraft Classic Era that reminds you to start combat logging when you enter selected raids or dungeons.

Features

Choose which raids and dungeons trigger reminders.

On-screen reminder with OK, Snooze 2 Min, and Cancel buttons.

Settings saved separately for each character.

Quick selection buttons: Raids Only, Select All, and Select None.

Test mode to preview the reminder.

All seven Classic Era raids are enabled by default. Dungeons are disabled until selected.

How It Works

When you enter an enabled instance, a reminder appears after a short delay.

OK: Dismisses the reminder for your current visit.

Snooze 2 Min: Displays the reminder again after two minutes while you remain in that enabled instance.

Cancel: Dismisses the reminder for your current visit and cancels any pending reminder.

The addon does not automatically start combat logging. Type /combatlog to toggle logging. Clicking OK only acknowledges the reminder.

Configuration

Type /clr or /clr config to open the settings menu, then check the instances where you want reminders.

Instances that share a map use one selection:

Lower and Upper Blackrock Spire

All Scarlet Monastery wings

All Dire Maul wings

Both Stratholme entrances

Commands

Command

Action

/clr

Open settings

/clr config

Open settings

/clr test

Preview the reminder with a 10-second snooze

/clr hide

Dismiss the reminder and cancel pending timers

Manual Installation

Place the CombatLogReminder folder inside your Classic Era Interface/AddOns folder.

Confirm the folder contains CombatLogReminder.lua and CombatLogReminder.toc.

Restart WoW and enable Combat Log Reminder in the AddOns menu.

Feedback

When reporting a problem, include your game version, addon version, instance name, and any Lua error message.
